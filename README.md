# Aqura Desktop — установщики и обновления

Здесь только готовые файлы Aqura Desktop. Код приложения в этом репозитории не хранится. Каждый релиз выпускается автоматически.

## Установка (один раз)

Скачайте файл из [последнего релиза](https://github.com/getaqura/aqura-desktop-releases/releases/latest).

**Mac**

1. Скачайте `.dmg` для своего Mac: `arm64` — Apple Silicon (M1 и новее), `x64` — Intel.
2. Перетащите Aqura в «Программы».
3. При первом запуске macOS скажет, что не может проверить разработчика. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

**Windows**

1. Скачайте `Aqura-Setup-<версия>-x64.exe`.
2. Если появится SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае».

## Обновления

Дальше Aqura обновляется сама: раз в 6 часов она проверяет этот репозиторий. Когда новая версия скачана, Aqura сообщает: «Aqura X.Y.Z готова — перезапустите, чтобы обновить». Новая версия ставится по кнопке «Обновить» или при следующем выходе из приложения.

Каждое обновление проверяется по подписи (`latest.json.sig`, Ed25519) и по контрольной сумме sha512.
